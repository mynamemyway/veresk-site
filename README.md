# veresk-site
Лендинг для запуска трафика в работающий бизнес (ребрендинг)

```
📁 veresk-site/                     (Корень проекта)
│
├── 📁 assets/                      (Главная папка всех статичных ресурсов)
│   │
│   ├── 📁 css/                     (Папка для стилей)
│   │   └── 📄 style.css            (Главный CSS-файл: переменные вверху, затем стили)
│   │
│   ├── 📁 js/                      (Папка для всех скриптов)
│   │   ├── 📄 main.js              (Общая логика: табы калькулятора, поп-апы, формы)
│   │   └── 📄 heather-animation.js (Изолированный код верескового поля)
│   │
│   ├── 📁 img/                     (Папка для картинок, иконок и графики)
│   │   ├── 📁 icons/               (SVG иконки, если есть)
│   │   └── 📄 master.png           (Фото, изображения)
│   │
│   └── 📁 fonts/                   (Папка для локальных шрифтов)
│
├── 📁 _archive/                    (Папка для старых исходников, вне сборки)
├── 📁 _dev/                        (Папка для черновиков кода, вне сборки)
│
├── 📄 .gitignore                   (Служебный файл для исключений Git)
├── 📄 index.html                   (Главный HTML-файл в корне)
└── 📄 README.md                    (Документация проекта)
```
